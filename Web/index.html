HTML ve CSS NEDİR?

HTML Nedir?

HTML (Hypertext Markup Language), web sayfalarını oluşturmak için kullanılan bir işaretleme dilidir. HTML, metin, resim, video ve diğer medya türlerini web sayfalarında düzenlemek ve sunmak için kullanılır.

CSS Nedir?

CSS (Cascading Style Sheets), web sayfalarının görünümünü ve düzenini kontrol etmek için kullanılan bir stil dilidir. CSS, HTML ile birlikte kullanılarak web sayfalarının tasarımını ve kullanıcı deneyimini iyileştirir.


BAŞLIK TAG'LERİ

HTML'de başlık tag'leri, web sayfalarında başlıkları belirtmek için kullanılır. Başlık tag'leri, h1 ile h6 arasında değişen altı farklı seviyede bulunur. h1 en yüksek seviyedeki başlığı temsil ederken, h6 en düşük seviyedeki başlığı temsil eder.

İÇERİK TAG'LERİ

HTML'de içerik tag'leri, web sayfalarında metin, resim, video ve diğer medya türlerini düzenlemek ve sunmak için kullanılır. İçerik tag'leri, web sayfalarının yapısını ve içeriğini belirler.

< p >Paragraf
< span > Metin parçası
< strong > Kalın metin
< em > İtalik metin
< a href="#">Bağlantı
< img src="#" alt="Resim" />
< table > Tablo
< div > Bölüm
